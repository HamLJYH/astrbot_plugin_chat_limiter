# AstrBot 聊天限制器插件

限制用户与 AI 聊天的白名单插件。

## 功能

- **白名单管理**：管理员可将用户添加至受信任名单
- **权限控制**：
  - 受信任用户：群聊和私聊均可使用 AI
  - 非受信任用户：仅限群聊使用 AI，私聊将被拒绝

## 安装

1. 将插件文件夹复制到 AstrBot 的 `data/plugins/` 目录下
2. 重启 AstrBot 或热重载插件
3. 在 WebUI 中配置插件参数

## 指令

| 指令 | 权限 | 说明 |
|------|------|------|
| `/trust <QQ号>` | 管理员 | 添加用户到受信任名单 |
| `/untrust <QQ号>` | 管理员 | 从受信任名单移除用户 |
| `/trustlist` | 所有人 | 查看受信任用户名单 |
| `/checktrust [QQ号]` | 所有人 | 检查用户信任状态（留空检查自己） |
| `/limiter <on/off/status>` | 管理员 | 开启/关闭/查看限制器状态 |

## 配置项

在 AstrBot WebUI → 插件配置中可调整：

- `deny_private_message`：非白名单用户私聊时的拒绝提示

## 工作原理

插件通过监听所有消息事件，在 AI 处理前进行拦截：

1. 检查消息发送者是否为管理员 → 放行
2. 检查消息发送者是否在白名单 → 放行
3. 检查是否为私聊 → 拒绝并提示
4. 群聊消息 → 放行

## 注意事项

- 管理员始终不受限制
- 白名单数据保存在 `data/chat_limiter/trust_list.json`
- 非白名单用户私聊时，插件会阻止事件继续传播，AI 不会处理该消息
